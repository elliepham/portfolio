# STIGS

This repository contains PowerShell scripts for automating the remediation of STIG (Security Technical Implementation Guide) findings on Windows 11 systems. The goal of this project is not only to ensure compliance with security best practices but also to **improve my proficiency in using PowerShell** for real-world system administration and security tasks. Each script corresponds to a specific STIG ID and applies the recommended configuration automatically.
